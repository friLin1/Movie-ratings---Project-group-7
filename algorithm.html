Our Algorithm

Our algorithm helps a user find movies from the dataset. The user can type part of a movie title or genre. The program checks each movie and shows matching results.

Try our simple movie search


The algorithm looks at each movie one at a time. This is called a linear search. It is simple and suitable for a dataset of 50 movies.
