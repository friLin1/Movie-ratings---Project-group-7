1. Purpose & Problem Definition

The primary goal of our algorithm (movie_algorithm.py) is to process a structured catalog of 50 English-language feature films (Movie_Dataset.csv) and extract high-performing titles that meet a specific quality threshold: a IMDb rating of 8.5 or higher.

By automating this filtering process, the program transforms raw tabular data into a refined catalog of top-rated movies, demonstrating how computational logic directly serves data filtering objectives.

2. Core Algorithmic Constructs Used

Our implementation incorporates the three fundamental building blocks of algorithm design:

  • Sequence: The program executes statements in a logical, step-by-step linear order—starting from importing necessary libraries, loading the dataset, evaluating entries, and concluding with printed summaries.
  • Iteration (Looping): A for loop iterates through all 50 movie records in the dataset to inspect each movie sequentially.
  • Selection (Conditional Logic): An if statement (if rating >= 8.5) checks each film's rating to selectively store qualifying titles into a filtered list.

3. Python Implementation (movie_algorithm.py)

Below is the complete Python code written to execute our data filtering pipeline:

import csv

# Step 1: Initialize lists to store data
all_movies = []
top_movies = []

# Step 2: Read and load the CSV dataset
with open('Movie_Dataset.csv', mode='r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    for row in reader:
        all_movies.append(row)

print("Starting the movie analysis...")

# Step 3: Iterate through movies and apply conditional selection
for movie in all_movies:
    rating = float(movie['rating'])
    if rating >= 8.5:
        top_movies.append(movie['title'])

# Step 4: Output the filtered results
print("\nHere are the highly rated movies (8.5+):")
for movie in top_movies:
    print("- " + movie)

# Step 5: Print summary count
total_count = len(top_movies)
print(f"\nTotal number of top-rated movies found: {total_count}")
print("Analysis complete.")

4. Step-by-Step Code Execution Breakdown

  1. Library Import & List Setup: We import Python's native csv module and set up two empty lists (all_movies and top_movies).
  2. Data Reading: We use csv.DictReader to convert each row of Movie_Dataset.csv into a key-value dictionary for easy attribute access.
  3. Data Conversion & Selection: As the program loops over each record, it converts the text-based rating string into a floating-point number using float() and tests whether rating >= 8.5.
  4. Output Generation: The qualifying movie titles are appended to top_movies, listed on the terminal, and tallied using len().
