MOVIE RATINGS

Our Dataset

1. What the Dataset Describes

This dataset contains a curated catalog of 50 feature films stored in Movie_Dataset.csv. Each row represents one film, and each column describes a specific attribute used for organising and processing movie data.

2. Data Fields & Attributes

The dataset contains the following six columns:

  • movie_id: Unique identifier for each film.
  • title: The title of the movie.
  • director: The director or directors listed for the film.
  • release_year: The film's release year.
  • genre: The genre or genres recorded for the film.
  • rating: The numerical rating recorded in the dataset.
