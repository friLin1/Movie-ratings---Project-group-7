1. Dataset Overview

This dataset contains 50 films stored in Movie_Dataset.csv. Each row represents one film, and each column describes a specific attribute. The dataset is available in CSV and Excel formats.

2. Why Did We Choose This Dataset?

We chose film data because it is familiar and easy to understand. It provides a practical example for demonstrating data organisation and algorithm design.

The collection contains films from different release periods and genres. With 50 records, the dataset is small enough to inspect and process within the scope of our project.

The selected fields can support operations such as searching for a film by title, filtering films by genre, and comparing ratings.

3. Data Fields and Attributes

The dataset contains six columns:

Column Description
movie_id A unique identifier for each film.
title The title of the film.
director The director or directors listed for the film.
release_year The film's release year.
genre The genre or genres recorded for the film.
rating The numerical rating recorded for the film.

5. Data Validation and Limitations

The dataset is intended to contain 50 film records with six columns. The CSV and Excel files should contain the same records and column names to ensure consistent use in the project.

Structural checks can identify missing values, duplicate identifiers, and formatting problems. However, these checks do not guarantee that every film detail or rating is factually accurate.

Some films may have more than one genre recorded in the same field. Any genre filtering operation must take this format into account.
