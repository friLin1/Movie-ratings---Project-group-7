Dataset Description

1. What the Dataset Describes

This dataset contains a curated catalog of 50 feature films stored in Movie_Dataset.csv. It provides structured metadata including titles, release years, genres, directors, and ratings for algorithmic processing.

2. Data Fields & Attributes

  • id: Unique numeric identifier (1–50).
  • title: The official title of the movie.
  • director: The primary director of the film.
  • year: The release year.
  • genre: The main cinematic genre.
  • rating: The audience rating on a 10-point scale.
  • runtime: Film duration in minutes.
