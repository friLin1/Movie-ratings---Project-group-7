Our Dataset

Dataset Overview

Our project uses a dataset of 50 films. Each row represents one film, and each column describes a specific attribute. The dataset is provided in Excel and CSV formats. Both files use the same six-column structure.

Why Did We Choose This Dataset?

We chose film data because it is familiar and easy to understand, making it suitable for demonstrating data organisation and algorithm design.

The dataset contains 50 films from different release periods and genres. This provides variety while keeping the collection small enough to inspect and process within the scope of our project.

The selected fields can support practical operations, such as searching for a film by title, filtering films by genre, and comparing their ratings. The dataset structure can therefore be used by the Movie Tracker algorithm to demonstrate these operations.

Dataset Structure

The dataset contains 50 records and six columns:

Column Description
movie_id A unique identifier for each film.
title The title of the film.
director The director or directors listed for the film.
release_year The film's release year.
genre The genre or genres recorded for the film.
rating The numerical rating recorded in the dataset.

Data Validation and Limitations

The dataset is organised into 50 film records and six columns. The CSV and Excel files should use the same column names and represent the same records so that they can be used consistently.

Structural checks can help identify missing values, duplicate identifiers, and inconsistencies in the file format. However, these checks do not guarantee that every film detail or rating is factually accurate. The source of the ratings should be documented if the values are verified against an external source.

Some genre fields contain more than one genre, separated by a slash. This keeps the dataset simple, but genre filtering must account for combined values.

Download the Dataset

The Excel file is convenient for viewing and editing the data. The CSV file is a plain tabular format that can be read by Python and used by the Movie Tracker algorithm.
