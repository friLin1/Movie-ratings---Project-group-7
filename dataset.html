1. What the Dataset Describes

This dataset contains a curated catalog of 50 films stored in Movie_Dataset.csv. It provides structured information about movie titles, directors, release years, genres, and ratings for data organisation and algorithmic processing.

2. Data Fields & Attributes

The dataset contains the following six columns:

  • movie_id: Unique identifier for each film.
  • title: The title of the movie.
  • director: The director or directors recorded for the film.
  • release_year: The release year of the film.
  • genre: The genre or genres recorded for the film.
  • rating: The numerical rating recorded in the dataset.
